# Assumptions & Engineering Decisions

This document records every default choice made where the build specification left room for discretion.

1. **Next.js 16 `proxy.ts` & `cacheComponents`**:
   - Next.js 16 deprecates `middleware.ts` in favor of `src/proxy.ts` exporting `proxy(request)`. Session refresh for `@supabase/ssr` is implemented in `src/proxy.ts`.
   - `cacheComponents` is disabled in `next.config.ts` so authenticated pages reading `cookies()` via `@supabase/ssr` render dynamically without requiring experimental PPR Suspense boundaries around every header/page.

2. **Synthetic Internal Email Domain for Supabase Auth**:
   - Supabase Auth requires an email format for `auth.admin.createUser`. Players never see or enter an email; the server derives `${lower(username)}@players.worldscoreboardarcade.com` with `email_confirm: true` so no outbound email is ever sent.
   - The Supabase password is `Wsa!` + first 56 hex chars of `HMAC_SHA256(SERVER_PEPPER, lower(username) + ":" + pin)`, keeping raw PINs out of the database and satisfying password complexity rules.

3. **Age Gate (`MIN_AGE`) & Legal Compliance**:
   - Configurable via `NEXT_PUBLIC_MIN_AGE` (default `13`).
   - Registration displays a friendly block below `MIN_AGE` and notes that younger players should have a parent or guardian's permission. The site owner should confirm jurisdiction-specific age-gating rules (e.g., COPPA, GDPR-K, DPDP) before public launch.

4. **Turnstile CAPTCHA in Local Development**:
   - When `NEXT_PUBLIC_TURNSTILE_SITE_KEY` and `TURNSTILE_SECRET_KEY` are unset, the registration flow activates a clearly labelled dev-mode bypass so local testing works out of the box. In production, set both keys to enforce Cloudflare Turnstile.

5. **Rate Limiting Store**:
   - Uses Upstash Redis REST API when `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` are set.
   - Automatically falls back to the Postgres `public.rate_limits` table via the `check_rate_limit` SECURITY DEFINER RPC (and an in-memory map if Supabase is not yet connected).

6. **Location Dataset & Lazy JSON Chunks**:
   - Pre-processed into `/public/data/geo/countries.json` (195 UN-recognized countries) and individual `/public/data/geo/{ISO2}.json` chunks loaded on demand when a country is selected.
   - Detailed states/provinces and official districts/cities are bundled for 20+ major countries (including India's official states/UTs and districts, US states, UK, Canada, Australia, Germany, France, Japan, Brazil, Indonesia, Pakistan, Nigeria, Philippines, South Korea, Mexico, Spain, Italy, South Africa, Singapore, UAE, New Zealand). Countries without bundled subdivision lists gracefully show optional free-text fields, and every level includes `"Other (type your own)"` with `state_source` / `district_source` tracked as `list`, `custom`, or `none`.

7. **Blurry Reveal Illustrations (`/public/assets/reveal/`)**:
   - 69 original crisp vector SVG illustrations and `/public/assets/reveal/manifest.json` are generated by `scripts/generate-reveal-assets.ts` (zero third-party trademarks or copyrighted art). Any item can be swapped to a custom PNG simply by updating its `image` path in `manifest.json`.

8. **Landing Page 3D & PNG Assets**:
   - The 3D scene (`src/components/landing/arcade-canvas.tsx`) renders procedural glossy Three.js primitives with studio lighting and is deferred via `next/dynamic(..., { ssr: false })` + `requestIdleCallback`.
   - `GameAsset` (`src/components/game-asset.tsx`) checks `/public/assets/png/*.png` first and falls back to glossy tactile vector badges until custom transparent PNGs are dropped in — requiring zero code changes when real assets are added.
   - On viewports `< 768px`, low-core devices (`hardwareConcurrency <= 2`), missing WebGL, or `prefers-reduced-motion`, the 3D canvas and Lenis smooth scrolling are automatically disabled in favor of lightweight static layers.

9. **Seed Data Separation**:
   - `profiles.is_seed` boolean column isolates all 200 seeded demo accounts (`pnpm run seed`) so `pnpm run unseed` removes only demo rows without affecting real players.
